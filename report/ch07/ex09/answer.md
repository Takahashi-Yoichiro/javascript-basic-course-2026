# 結果

```javascript
console.log("𠮷野家"[0]); // "\uD842"(単独の上位サロゲート。表示は � など)
console.log("👨‍👨‍👧‍👧"[0]); // "\uD83D"(単独の上位サロゲート。表示は � など)
```

# 考察

## "𠮷野家"[0]

「𠮷」(つちよし)は U+20BB7 で、BMP(基本多言語面、U+FFFF以下)の外にある文字であるため、UTF-16 ではサロゲートペアで表現される。JavaScript の文字列は UTF-16 のコードユニット列であり、[0] はコードユニット単位で要素を返します。BMP 外の文字は サロゲートペア(上位サロゲート + 下位サロゲート)の2コードユニットで表現され、U+20BB7 は \uD842\uDFB7 となる。そのため [0] は上位サロゲート \uD842 だけを返し、単独では文字として意味を持たない(表示不能な)値になる。ちなみに "𠮷野家".length は 4 です(見た目は3文字)。

## "👨‍👨‍👧‍👧"[0]

この絵文字は、複数の絵文字を ZWJ(U+200D) で連結した ZWJ シーケンスで、合計 11 コードユニット(.length === 11)、7 コードポイント([...str].length === 7)、書記素は 1 個。[0] は最初の 👨(U+1F468 = \uD83D\uDC68)の上位サロゲート \uD83D だけを返す。

# 補足

- サロゲート(surrogate) とは、UTF-16 において、BMP(基本多言語面、U+0000〜U+FFFF)に収まらない文字を表現するために使われる、特別な役割を持つ 16 ビットのコードユニットのこと。
- BMP(Basic Multilingual Plane、基本多言語面) とは、Unicode のコードポイント空間のうち、U+0000〜U+FFFF の範囲を指し、Unicode における「面(plane)」の 0 番目(第 0 面)にあたり、Plane 0 とも呼ばれる。BMP内には現代の主要な言語の文字、記号などが含まれる。
- UTF-16 では、BMP 内のコードポイントは 1 つのコードユニット(16 ビット)で表せる。一方、BMP の外(U+10000 以上)は、サロゲートペアの 2 コードユニットが必要。
