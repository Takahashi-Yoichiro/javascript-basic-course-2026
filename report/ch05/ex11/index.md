## ターミナルからデバッグする

このディレクトリで次のコマンドを実行します。ここで、`0` は自動的に空いているポート番号を選ばせる指定です。

```bash
node inspect --port=0 index.js
```

`debugger;` の行で実行が停止します。停止した状態で、次の操作を試してください。

- `n` — 次の行へ進む
- `s` — 次の関数呼び出し `addTax` の中へ入る
- `repl` — 対話モードで式を評価する。関数呼び出しの前は `price` や `taxRate`、関数の中では `tax` も確認できます
- `c` — 続行してプログラムを終了する

`s` で関数に入ったあと、`n` で次の行へ進んで計算途中の値を確認し、`c` で続行すると計算結果が出力されます。

デバッガーを使わずに通常実行する場合は、次のコマンドを使います。

```bash
node index.js
```
