1.

「パン」は次の 2 文字で構成される。

- パ：NFC では U+30D1
- ン：U+30F3

また、「パ」は NFD では次の 2 文字に分解されます。

- ハ：U+30CF
- 半濁点：U+309A

したがって、文字列リテラルは次のように書けます。

// NFC
"\u30D1\u30F3";

// NFD
"\u30CF\u309A\u30F3";

2.

Windows では、ファイルシステムや多くのアプリケーションで NFC が使用される。
macOS では、従来の HFS+ ファイルシステムで使用されていた NFD が使用される。
ただし、macOS でも最近の APFS ファイルシステムでは、ファイル名の正規化形式を保持するようになっている。
