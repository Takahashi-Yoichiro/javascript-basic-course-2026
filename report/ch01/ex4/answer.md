# 予想
- 開発者モードとHTMLファイルの開くタイミングに関係なく、`{answer: 42}` と `{answer: 0}` が順に表示される。

# 結果
- 開発者モードを開いた状態でHTMLファイルを開くと、`{answer: 42}` と `{answer: 0}` が順に表示される。
- HTMLファイルを開いた状態で開発者モードを開くと、`{answer: 0}` と `{answer: 0}` が順に表示 

# 考察
- HTMLが読み込まれたタイミングで、Scriptは実行されるが、console.logはオブジェクトの参照を表示する為、DevToolsを開くタイミングでオブジェクトの見え方が変わる。これを防ぐには、`./index-corrected.html`のように、console.logの引数に直接値を渡すように修正することで、常に期待した結果を得ることができる。
